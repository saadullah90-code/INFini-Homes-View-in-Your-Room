3. PRODUCT ACCURACY REQUIREMENT
============================================================

The generated 3D model should visually match the actual product as closely
as technically possible.

This is extremely important for furniture and mattresses.

The system must NOT intentionally redesign the product.

Preserve whenever visible:
- shape
- proportions
- dimensions
- cushions
- arms
- legs
- frame
- stitching
- seams
- buttons
- handles
- headboards
- mattress structure
- fabric appearance
- colors
- materials
- visible details

IMPORTANT LIMITATION:

A single 2D image cannot guarantee exact hidden/backside geometry.

Therefore the system should support:

1. Manufacturer-provided 3D/CAD model where available.
2. Multi-image reconstruction where multiple product images exist.
3. Single-image AI generation only when necessary.
4. Manual dimension calibration.

Never claim that an AI-generated model is mathematically identical to a
physical product when the source data cannot guarantee that.

10. IMAGE CHANGE PROTECTION
============================================================

Do NOT automatically regenerate a 3D model whenever a product image changes.

Instead:

1. Detect product/image changes using Shopify webhooks.
2. Recalculate an image_set_hash.
3. Compare it with the hash used for the approved model.
4. If changed:
   mark model as STALE or NEEDS_REVIEW.
5. Do NOT automatically spend Meshy credits.
6. Let admin decide whether to regenerate.

This prevents unexpected API charges.
